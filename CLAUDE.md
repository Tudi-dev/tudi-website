# tudi-website

Sitio portafolio en Astro + React (islas) + Tailwind v4 + content collections. Ver [CONTRIBUTING.md](./CONTRIBUTING.md) para arquitectura/buenas prácticas y [CODE_STANDARDS.md](./CODE_STANDARDS.md) para convenciones de código.

**Antes de dar cualquier tarea por terminada, correr `npm run verify`** (type-check + oxlint + stylelint + build). Todo lo demás en esos documentos aplica igual quien lo escriba, humano o Claude.
