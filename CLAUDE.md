# tudi-website

Sitio portafolio en Astro + React (islas) + Tailwind v4 + content collections. Ver [CONTRIBUTING.md](./CONTRIBUTING.md) para la guía completa de arquitectura y buenas prácticas.

**Antes de dar cualquier tarea por terminada, correr `npm run verify`** (type-check + lint + build). Todo lo demás en CONTRIBUTING.md aplica igual quien lo escriba, humano o Claude.
